# Minimal reproducers for the findings (one case line each; run with
#   grep -v '^#' repros.txt | while read -r l; do python3 hunt.py case "$l"; done
# ). Comment above each line: what GEOS returns vs the exact answer.

# 1. circleIntersectsLine (slope-intercept form): near-vertical segment.
#    GEOS reports (3,0), which is 2 units off the arc, and misses (3.0000000004, 3.9999999997).
AS 5 0 0 5 -5 0 3 0 3.000000001 10
#    Same, longer segment: GEOS finds nothing and distance() = 9995 instead of 0.
AS 5 0 0 5 -5 0 3 -10000 3.0000001 10000
#    GeometryNoder misses the node.
N 0 GEOMETRYCOLLECTION(CIRCULARSTRING(5 0, 0 5, -5 0), LINESTRING(3 0, 3.000000001 10))

# 2. Segment endpoint lying exactly on the arc is dropped (only arc control points are snapped).
#    Expected (3,4); GEOS reports nothing.
AS -3 4 4 3 0 -5 -3 -4 3 4
#    ... so the noder does not split the arc at (3,4).
N 0 GEOMETRYCOLLECTION(CIRCULARSTRING(-3 4, 4 3, 0 -5), LINESTRING(-3 -4, 3 4))
#    Result depends on segment direction: P->Q reports (-35,-120), Q->P does not.
AS -125 0 -100 75 -120 35 -35 -120 -245 142

# 3. Arc endpoint lying exactly inside the other arc (T-junction) is dropped.
#    Expected (-15,-20) (start of B, interior of A); GEOS reports nothing.
AA 0 -25 -15 20 -7 24 -15 -20 -112 51 49 28

# 4. Same circle, radii differ by 1 ulp -> treated as nested circles -> NO_INTERSECTION,
#    although the arcs share endpoint (-864,779) and overlap between (-854,4) and (-449,-875).
AA -864 779 -449 -875 -854 4 -449 -875 -854 4 -864 779
#    Noder output (read the JSON; the harness skips overlapping inputs): both arcs come back unsplit and overlapping.
N 0 GEOMETRYCOLLECTION(CIRCULARSTRING(-864 779, -449 -875, -854 4), CIRCULARSTRING(-449 -875, -854 4, -864 779))

# 5. Cocircular overlap built with the wrong orientation (CircularArcIntersector.cpp:407):
#    intersects(B,A) returns the overlap arc through (0,-5) instead of through (0,5).
AA -3 4 4 3 0 -5 3 4 -4 3 -5 0

# 6. containsAngle does not wrap angles >= 2*pi: closestPoints picks a point that is not on arc A
#    and distance() = 1.9501 although the true distance is 13 - sqrt(119.2) = 2.0821.
AA 0 -1 0.6 -0.8 0.8 -0.6 2 -4 3 1 2 6

# 7. Full circle noded at a single point loses 3/4 of the circle (length 8.28 -> 3.57).
N 0 GEOMETRYCOLLECTION(CIRCULARSTRING(0 0, 2 0, 0 0), LINESTRING(1 1, 1 3))

# 8. containsPoint on a full circle is true for any point.
AP 0 0 2 0 0 0 5 5

# 9. closestPoints(segment) returns (segment point, arc point) in the endpoint branch.
AS -5 0 0 5 5 0 -1 -10 1 -10

# 10. Linear/segment path: TWO_POINT_INTERSECTION with getNumPoints() == 0.
SS 0 0 10 0 2 0 8 0
#    Same through two collinear "arcs" (degenerate, so only visible in the JSON: type 2, nPt 0).
AA 0 0 5 0 10 0 2 0 4 0 8 0

# 11. getCenter in plain double: flat arc, radius 1.678e9 instead of 1.25e9, sweep 5.96e-8 vs 8e-8.
A 0 0 50 1e-6 100 0 1

# 12. Near-closed arc collapses to zero sweep (exact sweep ~2*pi, length ~2*pi).
A 0 1 0 -1 1e-17 1 0.01

# 13. Collinear "arc": getLength() = 1 but getLinearized() has length 5 (sanity only; read the JSON).
G CIRCULARSTRING(0 0, 3 0, 1 0)

# 14. GeometrySplitter path: duplicate arc + compound curve -> AssertionFailedException
#     (also via GEOSSplit with any edge).
N 1 GEOMETRYCOLLECTION(COMPOUNDCURVE(CIRCULARSTRING(-113 26, -106 -23, -17 -46), (-17 -46, -15.5 -48.25)), CIRCULARSTRING(-113 26, -106 -23, -17 -46))

# 15. Cocircular overlap leaves 1-ulp sliver arcs at (-3,-7); with preserve=1 (GEOSSplit) this throws
#     "Sections of CompoundCurve are not contiguous".
N 0 GEOMETRYCOLLECTION(COMPOUNDCURVE(CIRCULARSTRING(-3 1, 3 -7, -3 -7), (-3 -7, -1.5 -9.25)), CIRCULARSTRING(0 -8, -5 -3, -3 -7))

# 16. Degenerate arc (p1 == p2) makes the noder throw "point array size must zero or be an odd number >= 3".
N 0 CIRCULARSTRING(2 0, 0 0, 0 0)

# Oracle artefact (NTS.Proofs driver, not GEOS): oracle_arc ARC_ARC_XY misses the shared vertex (3,2).
AA 3 2 -3 2 0 -1 868 -402 651 -143 3 2
